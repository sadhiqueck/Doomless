# Changelog — Focus Extension

All notable milestones across the 8-week build will be documented in this file.

## [1.0.0] - 2026-10-17
### Added
- Complete Manifest V3 desktop Chrome extension for YouTube, Instagram, and TikTok.
- Zero-flash early CSS feed injection running at `document_start`.
- Floating sticky note swap layer with realistic paper drop-shadows, tilt, and pushpin.
- Interactive task checkboxes with progress percentage tracking.
- 5-minute "Let me through" cooldown mechanism with live timer and tab synchronization.
- 5 pastel note themes (Yellow, Blue, Green, Pink, Orange) with automatic dark mode adaptation.
- Full options dashboard with multiline paste, live preview, markdown file drag & drop, and GitHub Issues import.
- Dedicated statistics page with streak counter, 7-day completion bars, and 28-day activity heatmap.
- First-run 4-step onboarding wizard.
- Global keyboard shortcut (`Ctrl+Shift+F`) to toggle focus.
